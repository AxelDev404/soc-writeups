# SOC Writeups

Raccolta di writeup e report di analisi dal mio percorso verso il ruolo di SOC Analyst.

## Cosa contiene

- **phishing/** — Analisi di email di phishing: header, URL, allegati, IOC
- **network-analysis/** — Analisi di traffico di rete: PCAP, C2, esfiltrazione
- **windows-monitoring/** — Analisi di log Windows: Sysmon, Event ID, processi
- **linux-monitoring/** — Analisi di log Linux: auth.log, processi, persistenza
- **siem-triage/** — Triage di alert su Splunk: TP/FP, escalation, report

## Come sono strutturati i report

Ogni report segue lo stesso schema:

1. Contesto
2. Analisi (strumenti, query, ragionamento)
3. IOC trovati (defangati)
4. Verdetto
5. Cosa ho imparato
